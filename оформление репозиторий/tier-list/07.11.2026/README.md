Простое приложение для тир-листов. Работает в браузере и как приложение для Android.

## Что умеет

- **Свои ряды**: добавлять, удалять, переименовывать и менять цвет (до 10 рядов).
- **Карточки с текстом или со своими картинками.** Картинки можно выбрать кнопкой, перетащить файлами на страницу или вставить из буфера обмена. Они обрежутся до квадрата.
- **Перетаскивание** мышью и пальцем. Лишние карточки удаляются перетаскиванием в корзину.
- **Тёмная и светлая тема**, подстраивается под систему.
- **Несколько тир-листов**, переключение в выпадающем списке вверху, старые листы не теряются.
- **Всё хранится на устройстве**, в браузере или в приложении. Интернет не нужен (только для шрифтов, без них используется системный).

## Как установить

**Android.** Откройте раздел [Releases](https://github.com/Bread11YT/Tier-List-app/releases), скачайте `app-debug.apk` из последнего релиза и установите. Телефон попросит разрешить установку из неизвестных источников, это нормально для приложений не из Google Play.

**Браузер.** Откройте `docs/index.html` или версию на GitHub Pages:
`https://bread11yt.github.io/Tier-List-app/`

## Как собрать самому

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Меню Build, затем Build Bundle(s) / APK(s), затем Build APK(s).
3. Готовый файл лежит в `app/build/outputs/apk/debug/app-debug.apk`.

Или из терминала:

```
./gradlew assembleDebug
```

## Как устроен проект

Приложение это экран WebView, который открывает одну страницу.

```
app/src/main/assets/index.html          страница тир-листа (HTML, CSS и JS в одном файле)
app/src/main/java/.../MainActivity.kt   WebView и выбор картинок
docs/index.html                         копия страницы для GitHub Pages
docs/banner.svg                         анимированный баннер для README
.github/workflows/build-apk.yml         автоматическая сборка APK
```

Если меняете страницу, обновите обе копии: `app/src/main/assets/index.html` и `docs/index.html`.

## Выпуск новой версии

Создайте тег и отправьте его на GitHub:

```
git tag v1.0
git push origin v1.0
```

GitHub сам соберёт APK и прикрепит его к новому релизу. Вручную сборку можно запустить во вкладке Actions.

## Где хранятся данные

В `localStorage` браузера или приложения. Листы в браузере и в приложении хранятся отдельно, а при удалении приложения или очистке данных браузера пропадают.
